## 핵심 이슈

### [필독] Google Analytics Data Manager 베타: 데이터 연결은 간편해지지만 전환 중복 집계 주의
- **발표일:** Google 공식 업데이트 2026-11-06 / 후속 실무 분석 2026-11-08.
- **한줄 요약:** GA4 관리자 화면에 데이터 스트림·연결 제품·퍼스트파티 데이터 수집을 한곳에서 관리하는 Data Manager(베타)가 추가됐다. Google은 GA4와 Google Ads에 동일한 데이터 연결을 동시에 활성화하면 전환이 두 번 기록될 수 있다고 공식 경고한다.
- **주요 변경:** 관리 화면의 데이터 연결 맵에서 소스 → GA4 → Google Ads/Google Marketing Platform 흐름과 연결 오류를 시각적으로 점검할 수 있다. 새 연결은 GA4 Data Manager에서 시작하는 것이 권장되지만, Google Ads/GMP에 이미 설정한 연결은 기존 위치에서 관리해야 한다. GA4에 수집한 데이터는 연결된 Ads/GMP로 내려가지만 그 반대 방향으로는 흐르지 않는다. 현재 서브속성 및 롤업 속성은 Data Manager 랜딩 페이지 미지원.
- **왜 중요한가:** 광고 전환 수치가 중복 기록되면 보고서의 CPA·ROAS·전환율 판단이 왜곡될 수 있다. 특히 오프라인 계약, CRM 리드, 광고 플랫폼 데이터를 연결하는 팀은 성과 최적화 판단 전에 데이터 파이프라인을 점검해야 한다.
- **실무 적용:** (1) GA4 관리자 > Data Manager에서 현재 데이터 소스와 연결 상태 확인. (2) 기존 Google Ads/GMP의 데이터 가져오기·CRM·오프라인 전환 업로드와 동일한 연결이 중복 설정돼 있는지 대조. (3) 새 연결은 GA4에서 설정하되 기존 연결은 중복 생성하지 않음. (4) 변경 후 전환 수치 급증, 동일 주문/리드의 중복 집계 여부와 주요 전환 설정을 검증. (5) 베타 기능이므로 계정별 접근 가능 여부를 확인.
- **활용 아이디어:** 콘텐츠 마케터 포트폴리오에 `광고 유입 → 리드/구매 → GA4/광고 플랫폼 전환 측정` 퍼널을 넣고, 단순 CTR·조회수 외에 중복 집계 방지와 성과 검증 체크리스트를 제시. 면접에서는 AI·자동화 광고가 확대될수록 측정 데이터의 정확성이 중요하다는 관점으로 연결.
