# AI Content Trend Radar
### AI 기반 콘텐츠·마케팅 트렌드 수집 및 인사이트 아카이브

> 뉴스레터·웹·소셜 채널에 흩어진 콘텐츠·마케팅·AI 이슈를 AI를 활용해 수집하고,  
> **콘텐츠 마케터 관점의 인사이트와 실행 아이디어로 전환하는 개인 트렌드 레이더**입니다.

---

## About This Project

콘텐츠 마케터에게 트렌드를 빠르게 파악하는 것은 중요하지만, 여러 뉴스레터·플랫폼 공식 채널·소셜미디어를 매일 개별적으로 확인하려면 많은 시간이 필요합니다.

또한 같은 이슈가 여러 채널에서 반복되거나 광고성 정보와 실무에 영향을 주는 변화가 뒤섞여 있어, **많은 정보를 보는 것보다 필요한 정보를 빠르게 선별하고 해석하는 과정이 중요하다**고 판단했습니다.

이를 위해 ChatGPT 기반의 정기 브리핑 워크플로를 설계하고,

**수집 → 검증 → 중복 제거 → 중요도 분류 → 마케터 관점 해석 → 콘텐츠 아이디어 전환 → 주·월간 패턴 분석**

과정을 지속적으로 기록하고 있습니다.

---

## Why I Built This

- **정보 탐색 시간 단축**  
  여러 채널에 흩어진 정보를 한 번에 확인합니다.

- **주요 변화의 빠른 발견**  
  트렌드뿐 아니라 플랫폼 정책·알고리즘·광고·검색 노출·AI 도구·저작권 변화를 함께 확인합니다.

- **정보를 실행으로 연결**  
  단순 요약에서 끝내지 않고 “콘텐츠 마케터라면 어떻게 활용할 수 있을까?”까지 정리합니다.

- **AI 기반 업무 효율화**  
  AI에게 판단을 맡기는 것이 아니라 직접 설정한 수집 범위와 선별 기준을 바탕으로 반복적인 정보 탐색·정리 과정을 효율화합니다.

- **단발성 뉴스가 아닌 변화의 패턴 발견**  
  Daily Briefing을 Weekly Insight와 Monthly Report로 다시 분석해 반복되는 흐름과 구조적 변화를 찾습니다.

## Workflow

```text
NEWSLETTERS · WEB · SOCIAL CHANNELS
                ↓
          AI-ASSISTED SEARCH
                ↓
        SOURCE VERIFICATION
                ↓
          DUPLICATE MERGE
                ↓
       PRIORITY CLASSIFICATION
                ↓
      MARKETER'S INTERPRETATION
                ↓
       CONTENT APPLICATION IDEA
                ↓
         DAILY BRIEFING
                ↓
         WEEKLY INSIGHT
                ↓
         MONTHLY REPORT
```

1. **Collect** — 새로운 뉴스레터·웹·공개 소셜 정보를 수집합니다.
2. **Verify** — 공식 자료와 신뢰할 수 있는 출처로 내용을 확인합니다.
3. **Filter** — 광고성·중복·출처 불명확 정보를 제외합니다.
4. **Prioritize** — 최신성과 콘텐츠 마케팅 영향도를 기준으로 중요도를 분류합니다.
5. **Interpret** — 콘텐츠 마케터에게 어떤 의미가 있는지 해석합니다.
6. **Apply** — 콘텐츠 기획·카피·SNS 운영·광고 등에 활용할 아이디어를 도출합니다.
7. **Archive** — 날짜별 Daily Briefing으로 축적합니다.
8. **Connect** — Weekly Insight에서 반복 이슈와 변화의 방향을 연결합니다.
9. **Synthesize** — Monthly Report에서 한 달의 핵심 변화와 실무 대응을 압축합니다.

## Insight Layers

### 01. Daily Briefing — What happened?

매일 새롭게 확인된 이슈를 원본 데이터처럼 기록합니다.

- 핵심 이슈
- 한 줄 요약
- Why It Matters
- Priority
- Action Point
- Portfolio / Content Idea
- Sources
- 검증·제외 로그

### 02. Weekly Insight — What is changing?

Daily Briefing을 다시 나열하지 않고 **한 주 동안 반복된 흐름과 서로 다른 이슈의 연결 관계**를 분석합니다.

예:

`AI 콘텐츠 증가 → 신뢰 문제 증가 → 사람의 경험·검수 중요성 상승`

### 03. Monthly Report — What should a marketer change?

한 달간 쌓인 Daily·Weekly 데이터를 바탕으로 **구조적 변화, 플랫폼 변화, 소비자 변화, 실무 액션**을 정리합니다.

월간 리포트의 목표는 뉴스 TOP 10이 아니라,

> **“그래서 다음 달 콘텐츠 마케터는 무엇을 다르게 해야 하는가?”**

에 답하는 것입니다.

## Priority System

### 🔴 필독 · MUST READ
빠르게 확인하고 대응할 필요가 있는 변화

- 주요 플랫폼 알고리즘·노출 정책 변경
- 광고 운영에 직접 영향을 주는 업데이트
- AI·콘텐츠 저작권 및 표시 정책 변화
- 콘텐츠 제작 방식에 영향을 주는 주요 AI 업데이트

### 🟠 주목 · WATCH
콘텐츠 기획에 활용할 가능성이 높은 변화

- 새롭게 확산되는 콘텐츠 포맷
- 소비자 행동·관심사 변화
- 새로운 밈과 표현 방식
- 브랜드 캠페인 및 플랫폼 신기능

### 🟡 참고 · REFERENCE
장기적으로 참고할 가치가 있는 정보

- 업계 사례
- 새로운 서비스와 도구
- 소비 문화 변화
- 장기적인 콘텐츠·마케팅 트렌드

## Trend → Insight → Action → Content

```text
TREND
무엇이 변하고 있는가?

↓

INSIGHT
소비자와 콘텐츠에는 어떤 영향을 주는가?

↓

ACTION
콘텐츠 마케터라면 무엇을 바꿔야 하는가?

↓

CONTENT
어떤 콘텐츠로 실행할 수 있는가?
```

이 프로젝트의 목적은 많은 트렌드를 저장하는 것이 아니라, **발견한 변화를 실제 콘텐츠 아이디어와 실행 방식으로 연결하는 것**입니다.

## AI Usage

AI는 **정보 탐색과 정리를 효율화하는 보조 도구**로 활용합니다.

정보 수집 범위와 중요도 기준을 직접 설정하고, 출처 확인·광고성 정보 제외·실무 활용 여부 판단을 거쳐 필요한 정보만 선별합니다.

또한 Daily Briefing의 반복 정보를 Weekly·Monthly 단계에서 다시 연결해 패턴을 발견하되, 최종 해석과 콘텐츠 활용 방향은 콘텐츠 마케터 관점에서 검토합니다.

> AI를 사용하는 것 자체보다  
> **AI를 어떤 기준으로 활용하고 결과를 어떻게 실무에 연결하는가**를 중요하게 생각합니다.

## Goal

**트렌드를 뒤늦게 따라가는 사람이 아니라, 변화를 먼저 발견하고 콘텐츠에 적용할 수 있는 마케터가 되는 것.**

AI를 활용해 정보 탐색에 드는 시간을 줄이고, 그 시간을 **소비자 이해·인사이트 해석·콘텐츠 기획과 실행에 더 많이 사용하는 것**이 이 프로젝트의 목표입니다.
